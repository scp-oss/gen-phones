# gen-phones

«Генератор новых номеров для FreePBX» — веб-сервис на Go с формой: указываете
начальный номер и количество — получаете CSV в формате FreePBX Bulk Handler
→ Extensions (105 колонок, CRLF, внутренние счётчики вроде `ringtimer`,
`dtmfmode`, `findmefollow_*` рассчитываются с теми же смещениями от номера,
что и в эталонном экспорте). Формат сверен с исходным кодом FreePBX
(`Core.class.php`, `Findmefollow.class.php`) — используются ровно те поля,
что читает штатный импорт Bulk Handler.

Скачанный файл называется `Phones-Pool_<начало>-<конец>.csv`, например
`Phones-Pool_2358-2505.csv` — сразу видно, какой диапазон номеров внутри.

## Настройка порта

Порт целиком настраивается через `.env` в корне проекта:

```
PORT=8080
```

Это значение читает и сам Go-сервис при старте (если переменная окружения
`PORT` не задана явно), и сборка Docker-образа.

## Запуск локально (без Docker)

```sh
go run .
```

## Сборка и запуск в Docker

Порт из `.env` пробрасывается в образ как build-arg (значение по умолчанию
внутри образа) и как переменная окружения контейнера.

Вариант 1 — через docker-compose (автоматически читает `.env`):

```sh
docker compose up --build -d
```

Флаг `-d` (detached) обязателен, если не нужно держать терминал открытым —
без него `docker compose up` остаётся в foreground и после сборки показывает
интерактивную панель Compose Watch (`w` — Watch, `d` — detach, `Ctrl+C` —
остановить контейнер). Это не ошибка и не вопрос, а просто ожидание ввода;
с `-d` сервис сразу уходит в фон.

Посмотреть логи потом:

```sh
docker compose logs -f
```

Вариант 2 — через docker build напрямую, скриптом, который сам подтягивает
`.env`:

```sh
./build.sh
docker run -d --rm --name gen-phones --env-file .env -p 8080:8080 gen-phones:latest
```

Чтобы поменять порт — просто отредактируйте `PORT` в `.env` и пересоберите
образ (`./build.sh` или `docker compose up --build -d`).

## Использование

1. Откройте `http://<адрес-сервера>:<порт>/`.
2. Укажите начальный номер (любое количество цифр, любая первая цифра) и
   сколько номеров сгенерировать.
3. Нажмите «Сгенерировать и скачать CSV» — браузер скачает
   `Phones-Pool_<начало>-<конец>.csv`.
4. Импортируйте файл через FreePBX → Admin → Bulk Handler → Extensions →
   Import.

**Важно:** Bulk Handler импортирует с `replaceExisting = true` — если
указанный диапазон пересечётся с уже существующими на АТС номерами, они
будут удалены и пересозданы заново, а не пропущены. Перед генерацией и
импортом убедитесь, что диапазон свободен.
