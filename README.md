# gen-phones

Веб-сервис на Go с формой: указываете начальный номер и количество —
получаете CSV в формате FreePBX `NEW-Pool.csv` (105 колонок, CRLF,
внутренние счётчики вроде `ringtimer`, `dtmfmode`, `findmefollow_*`
рассчитываются с теми же смещениями от номера, что и в эталонном экспорте).

## Настройка порта

Порт целиком настраивается через `.env` в корне проекта:

```
PORT=8080
```

Это значение читает и сам Go-сервис при старте (если переменная окружения
`PORT` не задана явно), и сборка Docker-образа.

## Запуск локально (без Docker)

```sh
go run .
```

## Сборка и запуск в Docker

Порт из `.env` пробрасывается в образ как build-arg (значение по умолчанию
внутри образа) и как переменная окружения контейнера.

Вариант 1 — через docker-compose (автоматически читает `.env`):

```sh
docker compose up --build
```

Вариант 2 — через docker build напрямую, скриптом, который сам подтягивает
`.env`:

```sh
./build.sh
docker run --rm --env-file .env -p 8080:8080 gen-phones:latest
```

Чтобы поменять порт — просто отредактируйте `PORT` в `.env` и пересоберите
образ (`./build.sh` или `docker compose up --build`).

## Использование

1. Откройте `http://localhost:8080/`.
2. Укажите начальный номер (любое количество цифр, любая первая цифра) и
   сколько номеров сгенерировать.
3. Нажмите «Сгенерировать и скачать CSV» — браузер скачает `NEW-Pool.csv`.
